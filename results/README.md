# results

This directory stores derived tables and figures.

The bundled public result package is:

- `tables/paper_official_20260627/`
- `figures/paper_official_20260627/`

These files are derived from complete GPU raw runs and are included so readers can audit the paper-facing figures, tables, and admission-policy claims. New local experiments can write summaries, policy evaluations, queue replays, and figures under a new tag in the same directory structure.
